# NexusAI

This repository contains both the frontend and backend for the NexusAI project.

## Project Structure

- **ai-assistant-backend/**: Java Spring Boot backend API
- **ai-personal-assistant/**: Next.js frontend application

---

## Getting Started

### Backend (Spring Boot)

1. Navigate to the backend directory:
   ```sh
   cd ai-assistant-backend
   ```
2. Build and run the backend:
   ```sh
   ./mvnw spring-boot:run
   ```
3. The backend will start on [http://localhost:8080](http://localhost:8080)

### Frontend (Next.js)

1. Navigate to the frontend directory:
   ```sh
   cd ai-personal-assistant
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```
4. The frontend will start on [http://localhost:3000](http://localhost:3000)
